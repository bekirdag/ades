# TNL / ADES audit, 14 October 2026

The audit checked every retained text and ADES projection in the exported TNL corpus, without sampling. Deterministic checks are not a human factual verification of every claim. Originals, per-record findings, text hashes, requests and replay responses are retained privately at `/home/wodo/adestool-audits/2026-10-14`.

## Coverage

18,943 news stories; 2,135 editorial posts; 67 story enrichments; 11 editorial editions; 1,033 assistant outputs; 10,361 revisions; 1,437 research sources; entity/path/tag records and source joins. The text ledger covers 890,860 string occurrences (263 million characters). 7,013 retained upstream events include ADES outputs, covering 5,828 story IDs. Complete historical ADES responses are unavailable for 13,115 stories; their saved TNL projections were still checked.

All 21,156 primary public texts were replayed with an explicit finance-us-en extraction profile and dependency packs. This controlled comparison does not reconstruct historical request options. Offline graph tracing separately tests connectivity and source provenance, not the correctness of a market forecast. Editorial repair uses the live news-analysis contract on each final published text.

## What works

* APIs, pack installation and package build/smoke checks work on Raijin.
* ADES returns structured identities, mention surfaces, artifact versions and source-provenanced graph edges.
* Impact analysis can abstain when no compatible terminal exists; an empty list is valid.
* The repaired Apple earnings example returns an organization using finance-en 0.2.3.
* Published-content retention guards and regression checks pass; corrections preserve prose, URLs and original metadata.

## Categorized failures and fixes

| Category | Evidence | Fix / status |
| --- | --- | --- |
| Research contamination | Editorial composition and reconciliation union source-story entities/paths. India analysis had 3,924 entities and 535 paths; 240 posts exceeded 32 entities and 129 exceeded 16 paths. | Remove both unions. Compute metadata from final title/dek/thesis/section prose only; retain exact input hash and full ADES response. Archive repair in progress. |
| Fabricated path display | 1,286 editorial posts contain arrow strings. Prompts demanded causal chains and legacy backfill fabricated them from headings. | Remove requirements/backfill. Display entity targets only; keep structural graph evidence separately. India corrected to 12 entities and 3 targets. |
| Invalid finance person taxonomy | Geographic-person flags affect 2,368 records; institution/date-person flags affect 1,438 records across saved projections and outputs. | Whole-name taxonomy guards; remove 428 aliases in seven pack releases and 660 invalid graph nodes/5,208 incident edges. Preserve original artifacts. |
| Ambiguous issuer aliases | Apple initially missed; geographic and ordinary words could become issuer/ticker aliases. | Verified issuer aliases, corporate-reporting guard, geographic exclusions and generic vocabulary exclusions. TNL display additionally requires named, text-grounded entities. Remaining heuristic quality requires semantic review. |
| Lost impact anchors | Canonical ticker names differ from article surfaces; refs-only expansion dropped actual mentions. | Carry mention_texts through extraction and refs-only expansion; reject candidates lacking a source anchored in the current article. |
| Missing path evidence | 12,332 story projections retain impact IDs/scores without inspectable edges. | Retain full analysis responses for corrected/new editorial posts. Historical missing edges cannot be invented; news ingestion retention remains a separate integration limitation. |
| Missing generated-text analysis | 3,246 generated-content records lack an independently retained ADES response. | Analyze editorial final text before publication; retain response/hash/version. Assistant/enrichment/edition historical records remain audit findings until their separate producers adopt this contract. |
| Runtime reliability | News concurrency starved status workers; SQLite contexts leaked descriptors; missing vector seed labels raised exceptions. | Dedicated status executor, explicit SQLite close, missing-label guard; regression tests and full-corpus replay. |
| Review flags | 14,509 records have labels absent from display text; 907 have citation-retention flags; 333 have placeholder/replacement-character flags. | Per-record evidence retained. Alias/source differences can be legitimate; these counts are review queues, not proven factual errors or automatic deletion candidates. |
